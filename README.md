## About

I'm a Computer Vision / Machine Learning Engineer focused on building end-to-end vision pipelines, from data preparation and model development to optimized inference and application integration.

My work spans **object detection, segmentation, OCR, pose estimation, robotics perception, and geospatial computer vision**. I'm particularly interested in applying vision to **robotics, autonomous systems, remote sensing, and aerospace**.

## Focus Areas

- **Computer Vision:** Detection, instance segmentation, tracking, OCR, and pose estimation.

- **Geospatial AI:** SAR/EO imagery, GeoTIFF processing, oriented bounding boxes (OBB), and cross-domain evaluation.
- **ML Systems:** PyTorch, ONNX, quantization, FastAPI, and Docker.

## Featured Projects

### [SAR Ship Detection Pipeline](https://github.com/Aaryan2304/sar-ship-detection-pipeline)
End-to-end SAR ship detection with oriented bounding boxes, GeoTIFF tiling, and cross-domain evaluation from SSDD to Umbra SAR imagery.

- YOLO26s-OBB baseline on SSDD: **0.9868 mAP@50** and **0.7957 mAP@50:95**.
- Includes SAR-aware augmentation, annotation conversion, dataset quality control, and intensity-normalization experiments.

`Python` `YOLO26-OBB` `Rasterio` `FiftyOne` `OpenCV`

### [SAR2EO — SAR-to-EO Image Translation](https://github.com/Aaryan2304/sar2eo-pix2pix)
Pix2Pix-based translation of paired Sentinel-1 SAR VV patches into Sentinel-2 optical RGB imagery.

- Implements a U-Net generator and PatchGAN discriminator in PyTorch.
- Compares L1-only and adversarial training using LPIPS, FID, SSIM, and PSNR.

`PyTorch` `Pix2Pix` `Conditional GANs` `Sentinel-1/2` `LPIPS` `FID`

### [Sports Computer Vision Analytics](https://github.com/Aaryan2304/sports-ai) · [SportsVision+](https://github.com/Aaryan2304/sportsvision-plus)
Sports video-analysis projects covering player and ball detection, tracking, team classification, and pitch/court mapping with homography.

`YOLO` `RT-DETR` `ByteTrack` `Supervision` `OpenCV` `Homography`
